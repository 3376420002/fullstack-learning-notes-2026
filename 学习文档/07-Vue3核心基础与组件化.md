# 07｜Vue 3 核心基础与组件化

> 目标：能读懂和修改常见 Vue 组件，让 AI 按正确的响应式与组件通信方式开发。

[← 前端工程化](./06-Node.js、pnpm、Vite与create-vue工程化.md) · [学习首页](../README.md) · [Router 与 Pinia →](./08-Vue-Router与Pinia.md)

## 1. Vue 的核心

```text
响应式状态 + 声明式模板 + 组件化 + 组合式逻辑
```

开发者修改状态，Vue 更新相关 DOM，不需要手工 querySelector 后逐个修改页面。

应用启动过程：

```ts
const app = createApp(App)
app.use(router)
app.use(pinia)
app.mount('#app')
```

`createApp` 创建应用实例，`use` 安装插件，`mount` 把根组件渲染到 `index.html` 的容器。插件一般要在 mount 前安装。

## 2. 单文件组件

```vue
<script setup lang="ts">
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button type="button" @click="count++">
    点击 {{ count }} 次
  </button>
</template>

<style scoped>
button {
  padding: 0.75rem 1rem;
}
</style>
```

```text
script setup   状态和逻辑
template       HTML 结构与 Vue 指令
style scoped   当前组件样式
```

模板中的 `{{ expression }}` 可以读取状态、做简单运算和调用无副作用的格式化函数：

```vue
<p>{{ todo.title }}</p>
<p>{{ todo.completed ? '已完成' : '进行中' }}</p>
```

不要在模板中写复杂业务流程或修改状态；复杂派生值移到 computed，事件逻辑移到函数。

## 3. ref 与 reactive

```ts
const title = ref('')
const todos = ref<Todo[]>([])

title.value = '学习 Vue'
todos.value.push(newTodo)
```

脚本中 ref 使用 `.value`，模板会自动解包。

```ts
const form = reactive({
  title: '',
  priority: 0,
})

form.title = '学习 Vue'
```

实用选择：

```text
独立值、数组、可能为空、整体替换   ref
一组按字段修改的对象               reactive
```

直接解构 reactive 会失去响应式连接，需要时使用 `toRefs`。

## 4. computed

```ts
const remainingCount = computed(
  () => todos.value.filter((todo) => !todo.completed).length,
)
```

computed 用于从现有状态得到新值，有依赖追踪和缓存。能计算出来的数据通常不再单独保存一份。

computed 应尽量无副作用，不在里面发请求或修改其他状态。

## 5. watch

```ts
watch(
  () => route.query.q,
  async (keyword, _oldValue, onCleanup) => {
    const controller = new AbortController()
    onCleanup(() => controller.abort())
    await loadTodos(String(keyword ?? ''), controller.signal)
  },
  { immediate: true },
)
```

```text
computed   产生派生值
watch      监听明确来源并执行副作用
watchEffect 自动收集同步读取的依赖
```

不要用 watch 同步本可由 computed 直接得到的数据。

## 6. 常用模板指令

```vue
<form @submit.prevent="addTodo">
  <input v-model.trim="title" type="text" />
  <button type="submit" :disabled="!title">添加</button>
</form>

<p v-if="loading">加载中…</p>
<p v-else-if="errorMessage">{{ errorMessage }}</p>
<ul v-else>
  <li v-for="todo in todos" :key="todo.id">
    {{ todo.title }}
  </li>
</ul>
```

```text
:attr / v-bind   绑定属性
@event / v-on   监听事件
v-model          表单值与更新事件约定
v-if             创建或销毁
v-show           CSS 显示隐藏
v-for            列表渲染
```

可变列表使用稳定业务 ID 作为 key，不要使用数组下标。

`v-if` 与 `v-show` 都能控制显示，但成本不同：

```text
v-if     条件为假时不创建 DOM；切换成本较高，适合不常切换
v-show   DOM 一直存在，只切换 display；初始成本较高，适合频繁切换
```

`v-for` 与 `v-if` 不建议写在同一元素上。需要筛选列表时先用 computed 得到结果，再循环渲染。

## 7. Props 与 Emits

子组件：

```vue
<script setup lang="ts">
const props = defineProps<{
  todo: Todo
  disabled?: boolean
}>()

const emit = defineEmits<{
  toggle: [id: number]
  remove: [id: number]
}>()
</script>

<template>
  <button type="button" @click="emit('toggle', props.todo.id)">
    {{ props.todo.title }}
  </button>
</template>
```

父组件：

```vue
<TodoItem
  :todo="todo"
  @toggle="toggleTodo"
  @remove="removeTodo"
/>
```

```text
父组件状态 → Props → 子组件
子组件操作 → Emits → 父组件更新
```

Props 是只读输入，子组件不应直接修改父组件状态。

## 8. Slots 与 v-model

```text
Props   传数据
Emits   传事件
Slots   传模板结构
```

组件 `v-model` 默认约定：

```text
modelValue Prop
update:modelValue Event
```

较新的 Vue 3 项目可以使用：

```vue
<script setup lang="ts">
const model = defineModel<string>({ required: true })
</script>

<template>
  <input v-model="model" />
</template>
```

使用前确认项目 Vue 版本。

## 9. 生命周期与 DOM

```ts
onMounted(() => {
  window.addEventListener('resize', handleResize)
})

onBeforeUnmount(() => {
  window.removeEventListener('resize', handleResize)
})
```

生命周期适合连接和清理外部资源。普通派生逻辑优先 computed，条件副作用优先 watch。

状态更新后等待 DOM：

```ts
visible.value = true
await nextTick()
inputElement.value?.focus()
```

## 10. 异步页面状态

远程数据至少考虑：

```text
loading、error、empty、success
```

```ts
async function loadTodos() {
  loading.value = true
  errorMessage.value = ''

  try {
    todos.value = await todoApi.list()
  } catch (error) {
    errorMessage.value = normalizeApiError(error).message
  } finally {
    loading.value = false
  }
}
```

还要注意重复请求、旧请求覆盖新请求和组件卸载后的取消。

## 11. Composable

```ts
export function useTodos() {
  const todos = ref<Todo[]>([])
  const remainingCount = computed(
    () => todos.value.filter((todo) => !todo.completed).length,
  )

  function toggle(id: number) {
    const todo = todos.value.find((item) => item.id === id)
    if (todo) todo.completed = !todo.completed
  }

  return { todos, remainingCount, toggle }
}
```

Composable 复用有状态逻辑，组件复用 UI。每次调用通常创建独立状态；跨页面共享状态更适合 Pinia。

## 12. Provide 与 Inject

Props/Emits 适合直接父子通信。跨越很多中间组件传递同一上下文时，可以由祖先 `provide`、后代 `inject`：

```ts
const todoContextKey: InjectionKey<TodoContext> = Symbol('todo-context')

// 祖先组件
provide(todoContextKey, { selectedId, selectTodo })

// 后代组件
const context = inject(todoContextKey)
```

它适合主题、表单上下文、组件库内部协作，不适合隐藏任意全局业务状态。大型共享业务状态仍优先使用 Pinia，并用 `InjectionKey` 保持类型安全。

## 13. 组件拆分

```text
TodoListView
├─ TodoCreateForm
├─ TodoFilterBar
├─ TodoList
│  └─ TodoItem
└─ TodoEmptyState
```

适合拆分的信号：

- 能独立命名；
- 有明确输入输出；
- 被复用；
- 当前文件混合多个职责。

不要把每个 div 都拆成组件。

## 14. 常见错误

- 普通变量参与模板但没有 ref/reactive；
- 脚本中忘记 ref 的 `.value`；
- 直接修改 Props；
- 可变列表使用 index 作为 key；
- 用 watch 保存派生状态；
- 所有状态都放 Pinia；
- `v-html` 渲染未经清洗的用户输入；
- 组件卸载时没有清理监听器和请求。

## 15. 给 AI 的开发指令

```text
请在现有 Vue 3 + TypeScript 项目中实现 TodoList。
使用 script setup 和 Composition API。
Props 接收 todos，Emits 发出 toggle(id) 和 remove(id)。
列表使用 todo.id 作为 key，覆盖 loading、error、empty、success。
派生状态使用 computed，副作用使用 watch，不修改 Props，不使用 any。
完成后运行 type-check、lint、test 和 build。
```

## 16. 面试表达

> Vue 通过响应式系统跟踪状态依赖，状态变化后调度相关组件更新，而不是让开发者手工维护 DOM。

> ref 可以保存任意值并通过 value 访问；reactive 代理对象。选择重点是状态语义和团队一致性。

> computed 表达有缓存的派生值，watch 用于请求、存储等副作用。

> Vue 组件遵循单向数据流，父组件通过 Props 传数据，子组件通过 Emits 报告事件。

> Composable 复用逻辑，组件复用 UI，Pinia 负责跨组件共享业务状态。
