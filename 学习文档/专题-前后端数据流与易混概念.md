# 专题｜前后端数据流与易混概念

> 目标：把容易混淆的技术放回一次真实请求中，快速确认每项技术负责什么。

[学习首页](../README.md) · [MVC](./01-MVC分层架构.md) · [HTTP](./02-HTTP与HTTPS.md) · [JSON](./03-JSON数据格式.md)

## 1. 完整请求链

```text
Vue 输入
  ↓
TypeScript TodoCreate
  ↓ Axios 序列化
HTTP POST + JSON
  ↓
FastAPI Router
  ↓ Pydantic TodoCreate 校验
Service 业务规则
  ↓
SQLAlchemy Todo
  ↓ SQL
PostgreSQL
  ↓
TodoOut 序列化
  ↓ HTTP 201 + JSON
TypeScript TodoDto
  ↓
Vue 更新页面
```

这些技术不是相互替代，而是在不同边界工作。

## 2. 同一个 Todo 为什么有多个类型

| 类型 | 负责什么 | 运行时校验 |
| --- | --- | :---: |
| TypeScript interface | 前端编译期提示 | 否 |
| Pydantic Schema | API 输入输出契约 | 是 |
| Domain Object | 内部业务状态，可选 | 取决于实现 |
| SQLAlchemy Model | 数据库表和关系映射 | 负责 ORM 映射 |
| PostgreSQL Table | 最终持久化和约束 | 是 |

字段相似不代表应该合成一种模型。

## 3. schemas 与 models

```text
schemas/
├─ TodoCreate   创建请求
├─ TodoUpdate   更新请求
└─ TodoOut      公开响应

models/
└─ Todo         SQLAlchemy 数据库映射
```

Schema 负责校验、序列化和 OpenAPI；Model 负责表、字段、外键和关系。

数据库有 `password_hash`，公开响应也不应该包含它。

## 4. TypeScript 类型与运行时数据

```ts
const todo = (await response.json()) as Todo
```

这句不会检查 JSON，只让编译器相信数据是 Todo。

可靠链路：

```text
后端 Pydantic 校验和过滤
  +
OpenAPI 描述契约
  +
前端同步或生成类型
  +
重要外部数据运行时校验
```

## 5. MVC 与前后端分离

```text
MVC            代码职责怎样组织
前后端分离     页面与 API 怎样通信和部署
```

传统服务端 MVC 通常由服务器返回完整 HTML。

Vue + FastAPI 项目中：

```text
Vue            页面 View
FastAPI Router HTTP Controller 边界
Service        业务规则
Repository     数据访问
SQLAlchemy     持久化模型
```

现代项目更准确地说是分层架构，不必机械把所有文件塞进 M、V、C 三类。

## 6. Vue 仍然需要 HTML 和 CSS

```vue
<script setup lang="ts">
const title = 'TodoLab'
</script>

<template>
  <h1 class="title">{{ title }}</h1>
</template>

<style scoped>
.title {
  color: #2563eb;
}
</style>
```

```text
template   HTML 结构
script     JavaScript / TypeScript 逻辑
style      CSS 样式
```

浏览器最终仍运行 HTML、CSS 和 JavaScript。

## 7. JSON、FormData 与 Form

| 格式 | 适合内容 |
| --- | --- |
| `application/json` | 结构化业务数据 |
| `multipart/form-data` | 文件和普通字段一起上传 |
| `application/x-www-form-urlencoded` | 传统文本表单和部分认证流程 |

创建 Todo：

```ts
await http.post('/todos', { title: '学习接口' })
```

上传文件：

```ts
const formData = new FormData()
formData.append('file', file)
await http.post('/files', formData)
```

FormData boundary 交给浏览器生成。

## 8. Path、Query、Header 与 Body

| 位置 | 示例 |
| --- | --- |
| Path | `/todos/42` |
| Query | `?status=active&page=2` |
| Header | `Authorization: Bearer ...` |
| Body | `{"title":"学习"}` |

资源 ID 放 Path，筛选分页放 Query，认证放 Header，创建更新数据放 Body。

## 9. FastAPI 的 422

FastAPI 使用 Pydantic 校验请求。缺少字段、类型错误或约束失败时，默认常返回：

```text
422 Unprocessable Content
```

```text
400   通用错误请求
401   未认证
403   无权限
404   资源不存在
409   状态冲突
422   字段验证失败
500   未处理服务端异常
```

不能把 Pydantic 默认验证错误统一说成 400。

## 10. curl 的作用

```text
Vue + Axios → HTTP → FastAPI
curl ─────────→ HTTP → FastAPI
```

curl 可以绕过页面，直接确认 API 是否正常：

```powershell
curl.exe -i `
  -X POST "http://127.0.0.1:8000/api/v1/todos" `
  -H "Content-Type: application/json" `
  -d '{"title":"学习 curl"}'
```

如果 curl 成功但页面失败，重点检查 Axios 配置、Vite 代理、浏览器 CORS 和前端数据处理。

## 11. opacity 与隐藏

| 方法 | 可见 | 占布局 | 可能接收点击 |
| --- | :---: | :---: | :---: |
| `opacity: 0` | 否 | 是 | 是 |
| `visibility: hidden` | 否 | 是 | 否 |
| `display: none` | 否 | 否 | 否 |

`opacity: 0` 不等于元素不存在，也会影响整个元素及子内容。

只让背景透明：

```css
background: rgb(0 0 0 / 0.5);
```

## 13. 给 AI 的综合指令

```text
请按 Vue → Axios → FastAPI Router → Pydantic → Service → SQLAlchemy → PostgreSQL 的链路实现 Todo 创建。
分别定义前端 TodoCreate、后端 TodoCreate/TodoOut 和 ORM Todo。
说明每层输入输出，不用 TypeScript 断言代替运行时校验。
Router 不写业务和 SQL，Service 不依赖 HTTPException，响应不暴露内部字段。
完成后使用 curl、后端测试、前端 type-check 和 build 验证。
```

## 14. 面试表达

> 前端 TypeScript 类型是编译期契约，Pydantic 是后端运行时 API 校验，SQLAlchemy Model 是数据库映射。

> 前后端分离与 MVC 讨论不同维度，现代项目通常采用 Router、Service、Repository 等分层。

> Vue 单文件组件仍然由 HTML 模板、TypeScript 逻辑和 CSS 样式组成。

> 创建普通资源通常使用 JSON，上传文件通常使用 multipart FormData。

> FastAPI 请求字段校验默认常返回 422，curl 可以独立验证后端 API。
