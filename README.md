课程从第 07 课起采用面向使用和求职的结构：

```text
技术认知 → 核心写法 → 项目模式 → 常见错误 → AI 编程指令 → 面试表达
```

建议从 [MVC 分层架构](./学习文档/01-MVC分层架构.md) 开始，重点建立技术之间的联系、读懂项目代码，并学会准确地指挥 AI 完成开发任务。
